# Scale Foundation 2.0.0-rc.1 changes

Additive upgrade to the submitted complete-backend package. Original files remain unchanged.

New: PostgreSQL cs schema and runtime-role guards; forced RLS/tenant foreign keys; separate durable worker; shared rate buckets; revocable sessions; exact decimal accounting; independent factor approval; keyed create idempotency; versioned workflow; quota-reserved invoice uploads; private versioned S3 adapter; delayed uncertain-upload reconciliation; fail-closed ClamD client; bounded parser thread; immutable calculation snapshots and monthly aggregate updates; operational health/readiness/metrics; new responsive console; OpenAPI route inventory; migration/provision/backup/integrity/load-smoke scripts; local Compose/Docker/TLS-proxy examples; offline tests, unexecuted PostgreSQL integration suite and CI workflow; HLD/runbooks and preservation manifest.

Not added: a cloud deployment, proven scale/SLA, legacy data migration, security certification, SSO/MFA, cloud OCR, real official factor catalog, Scope 3, billing, multi-invoice allocations, historical correction workflow or automatic destructive retention. Source presence is not a claim that these infrastructure paths were executed.
