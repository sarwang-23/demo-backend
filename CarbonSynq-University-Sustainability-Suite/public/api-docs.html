Before using the API

Local demo only. Synthetic records and illustrative factors. Every business route requires a bearer session; tenant identity comes from that session. Uploaded scans do not undergo AI OCR.

Base address: http://localhost:5050/api/v1. Use Content-Type: application/json for JSON operations. Uploads use multipart field file. The original Express/Neon application's contract is separate.

Sign in

POST /api/v1/auth/login
Content-Type: application/json

{"email":"admin@carbonsynq.demo","password":"Demo@12345"}

Read data.token from the result and send Authorization: Bearer TOKEN. Other accounts: entry@carbonsynq.demo, reviewer@carbonsynq.demo, ceo@carbonsynq.demo, all using the same local demo password. Sessions expire after eight hours; logout revokes them.

Create a manual draft

POST /api/v1/activity-data
Authorization: Bearer TOKEN
Content-Type: application/json
Idempotency-Key: unique-request-id

{
  "reportingPeriodId": "44444444-4444-4444-8444-444444444444",
  "campusId": "22222222-2222-4222-8222-222222222222",
  "category": "PURCHASED_ELECTRICITY",
  "quantity": 1250,
  "unit": "kWh",
  "activityDate": "2026-10-02",
  "description": "CEO demo manual consumption"
}

Get building and campus IDs from GET /api/v1/meta. Quantity is actual consumption, not an invoice's rupee amount. Canonical units: electricity kWh; diesel/petrol litre; LPG kg; natural gas m3.

Review, verify and calculate

Use POST /activity-data/ID/submit as the entry's author/admin with {"version":1}. Use the version returned by each call for the next transition. Sign into a separate reviewer and call start-review, verify, then calculate. Verify blocks self-approval, including administrators. Only calculated records change emissions totals. Repeated calculation cannot add another result.

Invoice evidence

Upload one PDF, PNG, JPEG or TXT under 10 MB, inspect data.extraction, download the original with authenticated /documents/ID/download, and confirm through /documents/ID/create-activity. Submit all activity fields, version, vendor, invoiceNumber, optional amountInr, and reviewConfirmed:true. Text suggestions are never approved automatically.

Response and conflict handling

{"success":true,"data":{...},"requestId":"..."}
{"success":false,"error":{"code":"STALE_VERSION","message":"..."},"requestId":"..."}

Downloads and reports return file bytes directly. Refresh records after HTTP 409 rather than overwriting newer data. Do not automatically resubmit a non-idempotent request under a new key after a network failure. File and logical invoice duplicates also return 409. JSON is limited to 64 KB; API lists accept page and limit (maximum 100).

GET/api/v1/activity-data/{id}

Get a tenant-owned activity and calculation

PATCH/api/v1/activity-data/{id}

Edit a draft or rejected record

Original author or administrator. Editing a rejected record returns it to DRAFT.
DELETE/api/v1/activity-data/{id}

Delete a draft or rejected record

Original author or administrator. Audit retained; linked document returns to review required. A JSON body with version is required.
POST/api/v1/activity-data/{id}/submit

Submit an activity

Author or admin: DRAFT to SUBMITTED.
POST/api/v1/activity-data/{id}/start-review

Start review an activity

Reviewer or admin: SUBMITTED to UNDER_REVIEW.
POST/api/v1/activity-data/{id}/verify

Verify an activity

Reviewer or admin, never the author: UNDER_REVIEW to VERIFIED.
POST/api/v1/activity-data/{id}/reject

Reject an activity

Reviewer or admin: UNDER_REVIEW to REJECTED. Reason required.
POST/api/v1/activity-data/{id}/calculate

Calculate an activity

Reviewer or admin: VERIFIED to CALCULATED. Already-calculated replay returns the existing calculation.
GET/api/v1/documents

List original invoice evidence

POST/api/v1/documents/upload

Upload one original invoice

Admin/data-entry only. PDF, PNG, JPEG or TXT; one file up to 10 MB. Simple text extraction only, no AI OCR. Always requires human review.
GET/api/v1/documents/{id}

Get invoice metadata and suggested/reviewed fields

GET/api/v1/documents/{id}/download

Download the exact original bytes

Authenticated same-tenant evidence download, recorded in the audit trail.
POST/api/v1/documents/{id}/create-activity

Confirm reviewed fields and create an invoice-linked draft

Admin/data-entry only. Manual human confirmation required; money is not consumption. One document to one activity.
GET/api/v1/audit-logs

List tenant audit events

GET/api/v1/reports/summary

Get full activity ledger and calculated-only summary

GET/api/v1/reports/export

Download a JSON or CSV report

Exports all filtered activity statuses. Emissions/factors are filled only for calculated records; summary totals exclude pending activities. Not an audited inventory.
POST/api/v1/reporting-periods/{id}/lock

Lock a reporting period

Administrator only. JSON object body required; pending entries do not prevent locking. API-only control in this demo.
POST/api/v1/reporting-periods/{id}/unlock

Unlock a reporting period

Administrator only. JSON object body required; pending entries do not prevent locking. API-only control in this demo.

Source and operations
